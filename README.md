Static site for Framing of Central Florida, built with [Astro](https://astro.build) and Tailwind CSS.

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:4321](http://localhost:4321).

```bash
pnpm build
pnpm preview
```

`pnpm build` writes the static site to `dist/`. Any static host can serve that folder.
